🧪 テストケース作成のヒント:

このページでは、画面に表示されているポイント数値を変数に保存し、
四則演算で合計を検証するテストケースを作成してみましょう。

想定されるテストケース:
1. 「現在のポイント」の数値部分を変数Aに保存
2. 「今回獲得ポイント」の数値部分を変数Bに保存
3. 「キャンペーンボーナス」の数値部分を変数Cに保存
4. 「有効期限切れ予定」の数値部分を変数Dに保存
5. 四則演算: A + B + C - D = 計算結果
6. 「合計ポイント」が計算結果と一致することを確認
開発者向け情報:
現在のポイント数値id: current-display（例: "1,500"）
今回獲得ポイント数値id: earned-display（例: "300"）
キャンペーンボーナス数値id: bonus-display（例: "150"）
有効期限切れ予定数値id: expired-display（例: "200"）
合計ポイント数値id: total-display（例: "1,750"）

⚠ このページのテストで起きる問題:
数値部分だけを取得しても「カンマ」が含まれています。
そのまま四則演算コマンドで計算しようとするとエラーになります。

例:
取得値: "1,500" → カンマがあるため数値として扱えない
期待: 1500 + 300 + 150 - 200 = 1750

解決方法:
1. カンマを除去してから計算する
2. または、計算せずに画面の「合計ポイント」を直接検証する
